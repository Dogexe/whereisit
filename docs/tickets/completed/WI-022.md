# WI-022 — Color the Income/Expense stat-card icons

Status: Completed

Spec: `docs/specs/home-income-expense-icon-color.md`

Codex profile: luna-low

Risk tier: Low

## Goal

Recolor the Income and Expense stat-card icons (currently muted gray) to
green/red, reusing the existing income/expense color tokens already used
by each card's delta line.

## Acceptance criteria

- [ ] Income stat card's icon renders in `var(--color-income-700)`.
- [ ] Expense stat card's icon renders in `var(--color-expense-700)`.
- [ ] The "Income"/"Expense" label text next to each icon stays its
      current muted color — unchanged.
- [ ] No new color tokens introduced.
- [ ] No `iconAvatar()`/tinted circular background added — glyph color
      only.
- [ ] Existing related behavior remains unchanged: `.stat-card` layout,
      padding, value/delta typography, and every other screen's use of
      `arrow-down-left`/`arrow-up-right` icons.

- Match existing: `.stat-card .head` (`src/screens/home.js:225-233`,
  `styles.css:415-416`).
- Reuse: `--color-income-700` / `--color-expense-700` (already used one
  line below, same component, `home.js:228,233`).
- New design primitives required by this ticket: none.
- Mobile (<1024px) behavior: identical to desktop.
- Desktop (>=1024px) behavior: identical to mobile.

## Implementation guidance

- Likely files: `src/screens/home.js`, `styles.css`.
- Likely functions/modules: `renderHome()`'s stat-row markup
  (`home.js:225-233`), `.stat-card .head`/`.icon` rules
  (`styles.css:415-416`).
- Existing pattern to reuse: a per-card modifier class (e.g.
